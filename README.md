# 🚀 How to Run

### Clone the Repository

```bash
git clone https://github.com/KishanJangid5/FSD-Mini-Projects.git
```

### Navigate to Any Assignment

```bash
cd Assignment-01-JS-Calculator
```

### Install Dependencies (React / Node Projects)

```bash
npm install
```

### Start React Project

```bash
npm run dev
```

### Start Express Server

```bash
npm start
```

or

```bash
node server.js
```
